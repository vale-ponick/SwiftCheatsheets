# Method Chaining - с англ. "цепочка методов"

## ⚡️ Суть
Цепочка — пишу несколько методов подряд через точку.  
Результат первого идёт во второй, результат второго — в третий.

## 📝 Синтаксис

let result = array
    .filter { условие }
    .map { преобразование }
    .sorted()
    
✅ Примеры
Базовый — из задачи 3

let words = ["swift", "xcode", "playground", "debug", "compiler"]

let result = words
    .filter { $0.count > 5 }
    .map { $0.uppercased() }
    .sorted()

print(result) // ["COMPILER", "PLAYGROUND"]

С числами

let numbers = [3, 7, 0, -5, 8, -2, 10, -1, 4]

let result = numbers
    .filter { $0 % 2 == 0 }
    .map { $0 * $0 }

print(result) // [0, 64, 4, 100, 16]

🧩 Готовый кейс: очистка + фильтр + тернарник + сортировка

let dirtyArray = ["", "Swift", "  ", "iOS", " Dev ", "", "Closure"]

let cleaned = dirtyArray
    .map { $0.trimmingCharacters(in: .whitespaces) }
    .filter { !$0.isEmpty }
    .map { $0.count <= 4 ? "short" : "long" }
    .sorted()

print(cleaned) // ["long", "long", "short", "short"]

🔑 Что здесь происходит?
Шаг    Метод                    Результат
1    .map { trimming... }       Убираем пробелы по краям
2    .filter { !isEmpty }       Отбрасываем пустые строки
3    .map { ... ? ... : ... }   Превращаем длину в "short" или "long"
4    .sorted()                  Сортируем по алфавиту

🔥 Запоминалка
Чистим → Фильтруем → Преобразуем → Сортируем

📘 Шпаргалка: Цепочки методов в Swift

🔧 Базовый шаблон
guard let result = startValue
    .method1()           // 🪜 шаг 1: преобразование 1
    .method2()           // 🪜 шаг 2: преобразование 2
    .method3()           // 🪜 шаг 3: преобразование 3
else { return }          // ⚠️ если любой шаг вернул nil → выход

1️⃣ Пример 1: Чистка строки
guard let input = readLine()?    // 📥 1. Читаем строку из консоли (Optional)
    .trimmingCharacters(in: .whitespacesAndNewlines)  // ✂️ 2. Удаляем пробелы и переносы по краям
    .lowercased()     // 🔡 3. Приводим всё к нижнему регистру
else { continue }     // 🔁 4. Если nil → пропускаем итерацию
🎯 Где пригодится: Очистка ввода пользователя, поиск, сравнение строк.

2️⃣ Пример 2: Чтение файла
guard let json = try? String(contentsOf: url)    // 📂 1. Читаем файл, ошибка → nil
    .trimmingCharacters(in: .whitespacesAndNewlines)  // 🧹 2. Убираем пробелы и переносы по краям
    .data(using: .utf8)    // 🔄 3. Превращаем строку в бинарные данные (Data)
else { return }            // 🚪 4. Если ошибка / нет файла → выход
🎯 Где пригодится: Загрузка JSON с диска, чтение конфигов, работа с API.

3️⃣ Пример 3: Преобразование строки в массив чисел
let numbers = inputString
    .split(separator: " ")    // ✂️ 1. Разбиваем строку по пробелам → массив Substring
    .compactMap { Int($0) }    // 🔢 2. Превращаем каждый элемент в Int, отбрасывая nil
    .filter { $0 > 0 }    // 🔢 3. Оставляем только положительные числа
    .sorted()             // 📊 4. Сортируем по возрастанию
🎯 Где пригодится: Парсинг чисел из ввода, обработка CSV, анализ данных.

4️⃣ Пример 4: Работа с опционалами
let name = userDictionary["name"]?    // 🗝️ 1. Достаём значение по ключу (Optional)
    .trimmingCharacters(in: .whitespaces)    // ✂️ 2. Удаляем пробелы по краям
    .lowercased()                         // 🔡 3. Приводим к нижнему регистру
    .replacingOccurrences(of: " ", with: "_") // 🔄 4. Заменяем пробелы на подчёркивания
🎯 Где пригодится: Нормализация данных из словарей, JSON, форм.

5️⃣ Пример 5: Фильтрация и сортировка массива структур
let completedTasks = tasks
    .filter { !$0.isCompleted }    // #️⃣ 1. Оставляем только невыполненные задачи
    .sorted { $0.dueDate < $1.dueDate }    // 📅 2. Сортируем по дате выполнения
    .prefix(5)                            // #️⃣ 3. Берём первые 5
🎯 Где пригодится: Todo-менеджеры, списки дел, очереди задач.

📏 Правила:
| Правило | Пример |
|---------|--------|
| Методы применяются слева направо | `a.b().c()` |
| Каждый метод возвращает новое значение | — |
| `?.` — опциональная цепочка | `a?.b()` |
| `try?` — ошибка → `nil` | `try? a()` |

⚠️ Когда цепочка НЕ подходит:
| Ситуация | Что делать |
|----------|------------|
| Нужно отладить промежуточный результат | Разбить на переменные и print |
| Преобразования разных типов | Разбить на понятные шаги |
| Цепочка длиннее 4-5 методов | Читаемость падает — лучше разбить |
